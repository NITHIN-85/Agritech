FarmFlow - Smart Tracking for Smarter Agriculture 🌾

FarmFlow is a modern full-stack AgriTech platform focused on transforming agriculture through intelligent supply chain tracking, real-time monitoring, and smart farming solutions. The platform empowers farmers, buyers, and logistics providers by creating a connected digital ecosystem that improves transparency, productivity, and operational efficiency.

🌱 Smart Crop Monitoring:
Track crop growth stages, farming activities, harvest schedules, and field updates through an intelligent monitoring system.

🚚 Supply Chain Tracking:
Real-time tracking of agricultural products from farms to buyers, ensuring transparency, traceability, and efficient logistics management.

📊 FarmFlow Analytics:
Interactive dashboards with productivity insights, yield analytics, market trends, and operational reports for data-driven farming decisions.

🛒 Farmer-to-Buyer Marketplace:
A direct marketplace where farmers can connect with buyers, reduce middlemen dependency, and improve profitability.

🚜 Equipment & Logistics Support:
Simplified machinery rentals, transportation coordination, and logistics management for affordable agricultural operations.

# 🛠️ Technology Stack

## 🎨 Frontend
- React.js
- Lucide Icons
- Recharts (for data visualization)
- Vanilla CSS

## ⚙️ Backend
- Java 17
- Spring Boot 3.x
- Spring Security (JWT Authentication)
- Spring Data JPA

## 🗄️ Database
- H2 In-Memory Database
  - Used for rapid development and testing
